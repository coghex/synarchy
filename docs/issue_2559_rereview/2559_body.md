## Requirements

1. Create only `assets/textures/flora/saguaro/sprout_dead.png` as new
   artwork: **48×48 PNG, RGBA**, with fully transparent and opaque pixels.
   Use the landed `sprout.png` as the fixed reference; existing images
   remain unchanged.
2. Match the saguaro family: hard pixel edges, compact shading,
   restrained palette, transparent background, and no soil, dirt mound,
   painted shadow, or scenery. Preserve the reference's canvas placement
   and ground-contact row 46.
3. Depict a narrow, unbranched juvenile saguaro that is shrivelled and
   collapsed inward, desiccated tan-brown to grey, with ribs showing and
   no green tissue. It must read as a dead juvenile rather than a
   scaled-down adult skeleton or a healthy sprout merely recoloured.
4. During solve, choose and record the lower-band boundary used to
   preserve the reference's base. Follow `docs/asset_generation.md`,
   including its mandatory color-shifted band-restore post-pass. The
   finished image must preserve the reference's alpha silhouette from
   that boundary through the bottom of the canvas, including surrounding
   transparency. Slumping or narrowing above the preserved band is
   permitted. Record the boundary and verify the band against the
   unmodified reference; matching its ground row alone is insufficient.

## Acceptance

Run the image check against the completed PNG and its recorded boundary:

```bash
python3 - <<'CHECK'
import hashlib
import json
from pathlib import Path
from PIL import Image

root = Path("assets/textures/flora/saguaro")
reference = root / "sprout.png"
path = root / "sprout_dead.png"
evidence = json.loads(Path("docs/art/saguaro_sprout_dead_evidence.json").read_text())
band = evidence["lower_band_start_row"]
assert type(band) is int and 0 <= band <= 46
assert evidence["reference_sha256"] == hashlib.sha256(reference.read_bytes()).hexdigest()

base = Image.open(reference)
im = Image.open(path)
assert base.mode == "RGBA" and base.size == (48, 48)
assert im.format == "PNG" and im.mode == "RGBA" and im.size == (48, 48)
alpha = im.getchannel("A")
assert alpha.getextrema() == (0, 255)
assert alpha.getbbox()[3] == 47
box = (0, band, 48, 48)
base_mask = base.getchannel("A").crop(box).point(lambda value: 255 if value else 0)
dead_mask = alpha.crop(box).point(lambda value: 255 if value else 0)
assert base_mask.tobytes() == dead_mask.tobytes(), "lower-band silhouette changed"
print("OK", path, im.size, "preserved band begins at row", band)
CHECK
cabal build all
python3 tools/texture_subset_audit.py
cabal run exe:synarchy -- --preview flora/saguaro
```

Expected: the image check prints `OK`; build and audit pass; and the owner
approves the proposed image in native/enlarged and real preview evidence.
The audit checks declared texture paths and does not validate this
undeclared PNG by itself. Direct image checks and visual signoff remain
required.

The final PR contains this one new image and its associated evidence.
Existing images and production YAML remain unchanged. Required evidence
and signoff are completed in the art PR, before its final review and merge.
