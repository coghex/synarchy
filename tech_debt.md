### TD-1. Split the monolithic responsive-gameplay test suite

`Test.Headless.UI.ResponsiveGameplay` has grown to 4,195 physical lines, making it the largest tracked Haskell file in the repository. Its size reflects multiple independently evolving gameplay UI domains collected under one module rather than a single large table or inseparable scenario.

The module currently contains 18 top-level `describe` groups, 99 test cases, and 73 local JSON probe types with matching `FromJSON` instances. It covers HUD lifecycle and resizing, reserved regions, popups, log panels, unit information, inventory and container endpoints, build tools, and the etymology panel. Keeping all of these concerns in one compilation and review unit makes tests harder to locate, concentrates unrelated changes in the same file, and obscures which fixture and probe definitions belong to each subsystem.

**Evidence:**

**Handoff context:**
